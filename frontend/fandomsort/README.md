# FandomSort

## Overview
An interactive sorting algorithm visualizer that helps users understand how different sorting algorithms work through step-by-step visualizations.

## Tech Stack
- React + TypeScript
- Algorithm Visualizations

## Features
- Interactive sorting algorithm visualizer
- Multiple algorithms (Bubble, Quick, Merge, Heap, etc.)
- Customizable array size and speed
- Step-by-step visualization
- Comparison of algorithms
- Educational explanations

## Key Components
- Algorithm selector
- Array visualization component
- Control panel (play, pause, step, reset)
- Algorithm comparison view
- Educational tooltips

## Implementation Steps
1. Setup project structure
2. Implement sorting algorithms
3. Create visualization components
4. Add animation system
5. Build control panel
6. Add algorithm explanations
7. Create comparison mode
