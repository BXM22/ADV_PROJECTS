# Wordle Clone

## Overview
A faithful recreation of the popular word-guessing game Wordle with daily challenges, statistics tracking, and share functionality.

## Tech Stack
- React + TypeScript
- Vite

## Features
- Classic Wordle gameplay
- Daily word challenge
- Statistics tracking
- Share results
- Dark mode
- Keyboard input support

## Key Components
- Game board (6x5 grid)
- Keyboard component
- Statistics modal
- Share functionality
- Word validation logic

## Implementation Steps
1. Setup project structure
2. Create game board component
3. Implement word validation
4. Add keyboard input
5. Create statistics tracking
6. Add share functionality
7. Polish animations and UX
